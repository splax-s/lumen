lessons/chem/ice-floats.yaml
id: chem.ice-floats
place: kitchen/glass
threads: [particles]
needs: []
steps:
  - type: hook
    sim: tank { items: [ice, stone] }
    lumi:
      play: "Ice is hard like a stone. Why doesn't it sink?"
      deep: "Most solids are denser than their liquid..."
  - type: poke
    sim: tank { tray: [coin, cork, ice, apple] }
    done_when: dropped >= 3 and dropped has ice
  - type: predict
    choices: [smaller, same, bigger]
    answer: bigger
    hints: [nudge, clue, demo]
  - type: zoom
    sim: molecules { control: temperature }
    done_when: event == froze
  - type: name_it
    term: density
  - type: challenge
    sort: [log, stone, iceberg, bolt, oil, honey]
  - type: keep
    card: "Ice floats because freezing water spreads out."
How Lumi reacts in real time
Sim emits died→ Runtime adds step + learner state→ Lumi picks hint level→ Safety check→ Bubble

Scripted lines cover most moments with no AI call at all. The model is used for free questions, misconception diagnosis and new challenge variants, which keeps cost and risk down.
